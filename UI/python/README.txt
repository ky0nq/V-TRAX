폴더 및 시작 번호 설정 (2026-10-08)

예:
SAVE_DIR = Path(r"D:\capture\my_dataset")
START_NUMBER = 163654
지정 폴더에 capture_163654.png부터 저장합니다. 날짜 하위 폴더를 만들지 않습니다.
기존 최대 번호가 START_NUMBER 이상이면 기존 최대 번호 다음부터 저장합니다.
k 중단/재시작 시 번호를 이어가고, 앱 재실행 시 기존 PNG 번호를 확인합니다.
시작 번호는 CMD에 표시됩니다.
명령줄 --dataset-dir / --dataset-start는 필요할 때만 코드 설정을 덮어씁니다.
확대 화면에 추가 ROI 테두리를 그리지 않습니다. 영상의 bbox는 HDMI에 이미 포함된 것만 표시됩니다.

ESP32-CAM AP MAC 검색 (2026-10-08)
PC를 차량 ESP32-CAM Wi-Fi에 연결한 뒤 run_ui.cmd만 실행하세요.
기본 실행은 mac_discovery.py의 AP MAC 5C-01-3B-47-98-E0로 IP를 찾아 영상에 접속합니다.
main.py의 ESP32_CAM_URL = None이면 MAC 검색을 사용합니다. IP를 직접 입력할 필요가 없습니다.
UI가 Wi-Fi 연결 자체를 전환하지는 않습니다. mac_discovery.py는 유지하세요.
--esp32-cam-url로 직접 주소 지정, --esp32-cam-mac으로 다른 MAC 지정, --no-esp32-cam으로 비활성화 가능.

왼쪽 게이지 (2026-10-08 차량 제어 코드 기준)
DRIVE CMD / EST: 차량 내부 명령값 0~255를 0~100%로 환산한 추정 표시이며 실측 시속이 아닙니다.
A1~A5 목표 67/100/139/188/255 (약 26/39/55/74/100%).
상승 50, 하강 80, 관성 감속 10.2 명령값/초. 브레이크 우선, 차량 코드의 단계별 감속률 사용.
방향 전환 시 추정 출력을 0으로 만들고 엑셀 0단계 확인 후 재개합니다.
노란 표시와 TARGET는 선택 단계의 목표값, 큰 숫자는 시간에 따라 변하는 추정 명령값입니다.
PC가 수신한 명령으로 계산하므로 차량 실제 수신/모터 PWM/실제 속도를 측정한 값은 아닙니다.
